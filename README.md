# Boundary Lab：阶段上下文弹性实验

Boundary Lab 是一个可运行的研究原型，用于比较人类与多模态 LLM / Agent 面对完全相同的价格几何形状时，如何随着语义信息逐步增加而修正阶段分界点。

## 当前实验流程（v3）

每名参与者依次判断四条真实加密资产曲线：Bitcoin、Ethereum、Solana 和 BNB。曲线顺序按会话随机，但每条曲线内部的披露顺序固定；每一步都使用两个分界点划分三个阶段。

1. 只显示走势形状；
2. 显示相对坐标、标准化价格和周度数据结构；
3. 显示真实日期和周度时间轴；
4. 同时显示资产身份和美元价格；
5. 显示一张更长时间轴定位图，高亮当前 2020–2024 实验窗口；
6. 显示截取时间段内六个重点事件的位置、日期和中性名称。

四条走势 × 六步，共 24 次判断。每步切换前有独立的信息披露提示，页面持续标亮本轮新增信息。两个评分量表都使用 1–5，并默认选择中间值 3。每完成一个币种，系统先展示该币种的分界点快照、移动轨迹和个人摘要，再进入下一条走势。系统记录两个分界点、移动方向与幅度、信心、主观影响评分、判断依据标签、理由、披露阅读时间、首次移动时间、调整次数和总作答时间。

新版位于 `/`；完整旧版保留在 `/legacy`，便于回退和对照。

## 数据口径

四条曲线来自 Li Blockchain 项目中的 CMC 日频 Open 数据，使用与项目一致的“连续 7 个观测取均值”方式生成周度序列。为保证可比性，四条实验曲线采用共同观察窗口 2020 年 8 月至 2024 年 12 月，并分别在显示窗口内做 min–max 标准化；披露价格时只替换纵轴与读数，不改变几何形状。定位小图使用 2018–2026 的可用历史，Solana 则从其真实数据起点开始，不补造上线前数据。

数据审计确认三个口径：

- 原始 TSV：1,000 条；
- 按当前规则可用：993 条；
- 与原 MATLAB 分析冻结且逐条对应：678 条。

因此，本项目不沿用未经核验的“682 条”说法；正式抽样母库以 678 条冻结样本为可复现基准。当前四币种事件只是可追溯的预测试标注，正式研究前仍需独立预注册。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

默认地址为 `http://localhost:3000`。常用检查：

```bash
npx tsc --noEmit
npm run lint
npm test
```

## 关键文件

- `docs/PROJECT_FRAMEWORK_ZH.md`：完整研究问题、实验设计、指标和实施路线；
- `app/ExperimentV2.tsx`：四曲线、六步披露、逐币奖励页与总结果页；
- `app/ExperimentClient.tsx`：保留的旧版单曲线界面；
- `app/api/`：匿名会话与逐步决策写入接口；
- `db/schema.ts`：D1 数据结构；
- `public/data/asset-stimuli-v2.json`：四币种预测试刺激；
- `scripts/export_four_asset_stimuli.py`：从 Li Blockchain 源数据重建刺激；
- `drizzle/`：部署数据库迁移。

## 研究状态

这是方法与界面预测试版本，不是已经获批的正式人类受试实验。正式招募前仍需完成伦理审批、事件集独立预注册、反事实与伪事件对照、样本量 / 功效分析、刷新恢复与退出/删除机制，以及 Agent 批量运行器和锁定的模型版本协议。
