# Boundary Lab：阶段上下文弹性实验

Boundary Lab 是一个可运行的研究原型，用于比较人类与多模态 LLM / Agent 在面对同一条金融价格曲线时，如何随着语义信息逐层披露而修正阶段边界。

## 当前实验流程

同一条曲线连续呈现六轮，每轮都要求参与者用两个切点划分三个阶段：

1. 仅显示曲线形态；
2. 披露标准化坐标；
3. 披露资产身份；
4. 披露日期；
5. 披露美元价格；
6. 披露预注册的历史事件。

后一轮继承前一轮切点，参与者可以拖动修正。系统逐轮记录两个边界、归一化位置、对应日期、信心、理由与作答时间，并在结束时计算边界轨迹和总“上下文弹性”。

## 数据口径

原型曲线来自 Li Blockchain 项目中 `bitcoin.tsv` 的日频 Open 数据，严格复现项目使用的连续 7 个观测均值聚合方法，截取 2017–2024 年的 416 个完整周频块。

数据审计确认了三个不同口径：

- 原始 TSV：1,000 条；
- 按当前规则可用：993 条；
- 与原 MATLAB 分析冻结且逐条对应：678 条。

因此，本项目不沿用未经核验的“682 条”说法；正式抽样母库以 678 条冻结样本为准。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm ci
npm run dev
```

默认地址为 `http://localhost:3000`。常用检查：

```bash
npx tsc --noEmit
npm run lint
npm test
```

## 关键文件

- `docs/PROJECT_FRAMEWORK_ZH.md`：研究问题、实验设计、对照条件、指标、模型和实施路线图；
- `app/ExperimentClient.tsx`：六轮披露与交互切点界面；
- `app/api/`：匿名会话与逐轮决策写入接口；
- `db/schema.ts`：D1 数据结构；
- `public/data/bitcoin-2017-2024.json`：原型刺激；
- `scripts/export_bitcoin_stimulus.py`：从 Li Blockchain 源数据重建刺激的可复现脚本；
- `drizzle/`：部署数据库迁移。

## 研究状态

这是方法与界面试运行版本，不是已经获批的正式人类受试实验。正式招募前还需要完成伦理审批、事件集独立预注册、反事实与伪事件对照、样本量 / 功效分析，以及 Agent 批量运行器和锁定的模型版本协议。
