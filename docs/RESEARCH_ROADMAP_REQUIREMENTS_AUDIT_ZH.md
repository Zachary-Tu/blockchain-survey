# Research Roadmap 与网站实现对照审计

审计对象：用户提供的 `Research Roadmap` LaTeX 逻辑文件，以及当前第四版 M1 人类入口、Agent 模块入口、D1 数据库与研究者导出接口。

状态含义：**已满足**＝当前代码与自动化测试均覆盖；**部分满足**＝已有界面或数据基础，但仍有范围/方法差异；**待分析实现**＝不是参与者网页功能，需在采集后由统计脚本完成；**未实现**＝当前主系统没有对应模块。

## 1. 主实验数据采集

| Roadmap 要求 | 状态 | 当前实现与说明 |
|---|---|---|
| 人类和 LLM/Agent 均对六条序列作答 | 已满足 | 人类 `/m1` 固定六种资产；Agent `/agent` 的 M1 配置使用同一刺激包和同一六资产生成逻辑。 |
| 每条序列划分为三阶段，但不提供“阶段”定义 | 已满足 | 固定为 T2，要求两个分界点；T2 文案明确不提供定义。 |
| G0 匿名曲线 → GI1 序列类型 → GI2 时间与单位 → DI1 币名 → DI2 背景 → DI3 高优先级事件 → DI4 低优先级事件 | 已满足 | `combined` 路径固定为七层，后续内容不会提前显示。 |
| 每次记录两个中心 $c_1,c_2$ | 已满足 | 保存 `boundary_1/2_ratio`、索引与日期；ratio 是绘图区宽度比例。 |
| 每个中心附带对称不确定范围 $w_1,w_2$ | 已满足 | 连续旋钮记录 `halfWidthRatio` 和 `widthRatio`；前端与 API 均限制区间不跨出绘图区，保证关于中心对称。 |

| 同一测试者在所有披露层重复判断 | 已满足 | 每层依次完成六个单币种页面；下一层恢复同一资产上一层答案并显示虚线。 |

## 4. Research Questions and Measurement

Roadmap 的统计公式属于采集后的分析层。当前网站已经收集计算这些指标所需的核心原始变量，但尚未提供正式统计分析流水线。

| 分析要求 | 状态 | 所需数据是否已收集 |
|---|---|---|
| PCA 第一主成分上的 Hartigan dip test 与散点图 | 待分析实现 | 是：每个 tester/series/level 的 $(c_1,c_2)$ 均有记录。 |
| RQ1 组内位置离散度与 LLM/Human 比率 | 待分析实现 | 是。 |
| tester × series 交叉随机效应方差分解 | 待分析实现 | 是；Agent 必须以唯一 run ID 标记每个独立 sample。 |
| 不确定宽度离散度 | 待分析实现 | 是：半宽与全宽均保存。 |
| 宽度与 leave-one-out 共识距离的 Spearman 相关 | 待分析实现 | 是。 |
| RQ2 群体共识有符号/绝对偏移 | 待分析实现 | 是。 |
| Human-equivalence percentile、KS 检验与 tester-blocked bootstrap | 待分析实现 | 是，但需要足够的人类和独立 Agent 样本量。 |
| RQ3 基线修正、增量修正、revision rate | 待分析实现 | 是：ratio、index、date 与上一层答案均保存。 |
| 相对收敛、跨层方差分量和跨组差距轨迹 | 待分析实现 | 是。 |

## 5. 结论与正式采集前仍需冻结的事项

当前网站已经满足 **Roadmap 主实验的数据采集要求**，并覆盖 T1/T2/T3、三类序列和 M4 稳健性条件。它尚不能被称为满足 Roadmap 的“全部研究流程”，原因是：

1. Roadmap 中的 Hartigan dip、混合效应模型、Spearman、KS、blocked bootstrap、revision/convergence 等统计分析尚未实现为可复现脚本；
2. “评价算法/LLM 已检测转折点”的任务仍停留在保留原型，没有进入统一模块数据库；
3. Agent M1 目前在边界校验后仍包含额外的线索/理由标注阶段。它发生在当前边界提交之后，不改变本题边界，但可能影响下一披露层的认知状态；若主论文追求与人类 M1 完全同构，应在正式采集前为 Agent M1 固定为同一精简问题集；
4. Roadmap 的 revision threshold “one time unit”必须按分辨率明确操作化。主 M1 为 weekly，建议预注册为一个相邻周观测（也可直接使用已保存的 index 差判断）；
5. 需要预注册样本量、Agent 独立抽样次数、模型/版本、temperature、prompt 版本、缺失/中途退出处理、设备与低质量作答排除规则；
6. 设备类别是推断值，不应当作精确设备型号；正式招募还需完成所在机构要求的伦理审批、数据保存期限与撤回流程。

因此，准确结论是：**主实验网站与数据库采集层已就绪；扩展模块大部分就绪；统计分析流水线与一个算法边界评价模块仍待完成。**
