# Boundary Lab 第三版研究协议 v5 修订说明

## 1. 修订目的

`context-elasticity-multimetric-v5` 延续 v4 的多指标、四级披露、多分辨率和人类—Agent 对比框架，但把“阶段数量”和“任务类型”拆成完全配对的实验条件，并新增人类边界判断的不确定区间。

v4 中未被本文件替代的数据来源、指标定义、事件筛选、分辨率规则、伦理要求和 Agent 运行规范继续有效。

## 2. 六个判断条件

任务采用 `任务家族 × 分界点数量` 的 2 × 3 设计。分界点数量在会话开始前锁定，测试者不能在作答过程中增加或删除。

| 条件 | 任务家族 | 分界点 | 阶段数 | 主响应 |
| --- | --- | ---: | ---: | --- |
| A1 | 自主选择 | 1 | 2 | 点位与可能范围 |
| A2 | 自主选择 | 2 | 3 | 点位与可能范围 |
| A3 | 自主选择 | 3 | 4 | 点位与可能范围 |
| B1 | 评价预设 | 1 | 2 | 合理性评分 1–5 |
| B2 | 评价预设 | 2 | 3 | 合理性评分 1–5 |
| B3 | 评价预设 | 3 | 4 | 合理性评分 1–5 |

A/B 一一对应，使研究者可以在相同阶段复杂度下比较“主动构造边界”和“接受外部边界”两类判断。正式分析不应把两类主响应直接合并为同一个因变量。

## 3. 预设边界

B 类任务的 1、2、3 条预设边界分别由同一冻结脚本生成。算法在最多 240 个等距采样点上，对 `log(1 + value)` 的归一化序列寻找 SSE 最小的 2、3、4 个常数段。

这些边界只是可复现的“参考方案”，不是客观真值。网页和参与者说明均不得暗示算法方案正确。

## 4. 披露主题盲化

四级披露顺序不变，但界面执行严格的未来主题隐藏：

1. 当前层和已经完成的层显示真实名称；
2. 所有尚未到达的层只显示“？”；
3. 配置页同样不提前列出后续主题；
4. 只有上一轮提交后，转场页才公布下一层新增信息；
5. 提交后不能返回修改早期答案。

这项控制降低参与者预判后续资产身份、坐标或事件信息后提前调整边界的风险。研究材料、招募文本与实验主持话术也应避免提前列举披露主题，否则网页盲化会失去作用。

## 5. 上一层边界参照

A 类任务从第二层起，在主图中同时显示：

- 深绿色实线：本层当前可移动的分界点；
- 橙色虚线：上一层最终提交的分界点。

进入新一层时两者最初重合；参与者移动当前分界点后，橙色虚线留在原位。这样可以把“是否移动、向什么方向移动、移动多远”变成显式比较，而不是依赖记忆。

虚线位置来自上一层已经保存的响应，并在当前响应中作为 `previous_boundaries_json` 再次记录，以便审计实际展示给参与者的参照。

## 6. 边界不确定区间

### 6.1 测量方式

A 类任务的每个分界点同时包含：

- 中心点：参与者认为最可能的最佳分界位置；
- 对称可能范围：以中心点为中心的半透明色带。

第一次披露没有默认范围，参与者必须为每个分界点主动选择一个宽度。后续披露沿用上一层宽度，允许收窄、放宽或保持不变。

冻结的五档总宽度约为整条曲线的 2%、5%、10%、16% 和 24%，对应半宽 0.01、0.025、0.05、0.08 和 0.12。采用相对时间宽度，使日、周、月、年分辨率之间仍可比较。第三级披露真实时间后，界面同时显示区间起止日期。

### 6.2 边界附近的裁剪

若色带触及曲线起点或终点，显示区间裁剪到 `[0, 1]`。数据库同时保存所选半宽与裁剪后的上下界，因此分析时可以区分“选择的宽度”和“实际可见宽度”。

### 6.3 不变判断

A 类任务只有在中心点和可能范围都与上一层一致时，才视为“主响应未变化”。此时测试者必须主动确认保持原判断；只修改范围宽度也属于有效变化。

## 7. 新增记录字段

每层响应在 v4 字段基础上新增：

- `task_family`：`placement` 或 `evaluation`；
- `previous_boundaries_json`：当前层实际显示的上一层参照；
- `boundary_intervals_json`：每条边界的中心、所选半宽、裁剪后宽度、上下界索引、比例和日期；
- `first_uncertainty_ms`：本层首次调整可能范围的时间；
- `uncertainty_adjustment_count`：本层范围选择次数。

会话配置还记录目标分界点数量和范围策略。导出的参与者 JSON 与服务器记录使用同一字段结构。

## 8. 推荐分析

### 8.1 中心点弹性

对边界 `k`、披露层 `l`：

- 单步位移：`Δb(k,l) = b(k,l) - b(k,l-1)`；
- 绝对位移：`|Δb(k,l)|`；
- 总弹性：四层轨迹绝对位移之和；
- 保持不变概率。

在 A1、A2、A3 内分别建模，或在分层模型中加入分界点数量及其与主体类型、披露层的交互项。

### 8.2 不确定性弹性

- 区间总宽度及其逐层变化；
- 新信息后区间收窄、放宽或不变的概率；
- 中心点位移与区间宽度变化的相关性；
- 上一层中心是否仍落在本层可能范围内；
- 人类与 Agent 的区间覆盖率、宽度和校准差异。

Agent 必须用与人类相同的五档范围输出，不能用任意精度小数规避实验条件。

### 8.3 A/B 配对比较

B 类合理性评分使用有序 logistic 模型。A/B 可以在相同分界点数量下比较披露效应方向，但不能直接把边界位移与合理性分数当作同一尺度。

## 9. 当前状态

v5 是可运行的预测试协议，不等同于已经预注册或获得伦理批准的确认性研究。在正式收集前仍需冻结网页版本、刺激 JSON 哈希、数据库迁移、事件集、样本量方案和 Agent 提示词。
